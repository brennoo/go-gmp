# Security Policy

This is a pre-alpha library maintained by a single person. Only the latest
commit on the default branch is supported.

To report a vulnerability, please use
[GitHub's private security advisory feature](https://github.com/brennoo/go-gmp/security/advisories/new)
rather than a public issue. Include the affected commit, a description of the
impact, and steps to reproduce if possible.

Vulnerabilities in Greenbone Vulnerability Manager (`gvmd`), OpenVAS, or the
GMP protocol itself are out of scope — report those to the
[Greenbone project](https://www.greenbone.net/).
